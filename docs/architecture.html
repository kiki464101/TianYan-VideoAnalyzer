VideoAnalyzer Architecture

Qt 6.8.3 + OpenCV 4.5.5 实时视频流智能分析 · 多线程流水线 · 双 DNN 多目标 · LLM 摘要检索

核心流水线

  • • 采集线程 → 检测线程 → GUI 线程（Channel 解耦）
  • • DNN 与运动检测解耦：每 2 帧无条件推理
  • • 多人画面：共享关键帧 + N 条独立事件
  • • 双时间戳：timestamp_ms 显示 + video_position_ms 跳转

检测能力

  • • MobileNet-SSD 人体（conf≥0.3）+ NMS 去重
  • • ResNet-10 人脸（conf≥0.4）+ 最近人脸配对
  • • 每人独立：HSV 颜色 + Gabor 4×3 纹理
  • • 模型缺失优雅降级，不影响运动检测

检索与摘要

  • • summaries 独立表：每次摘要追加，不覆盖历史
  • • 双路搜索：description + keywords 反查 event_ids
  • • 点击定位 / 上一处 / 下一处循环跳转
  • • 摘要 Tab 事件列表也可单击跳转
